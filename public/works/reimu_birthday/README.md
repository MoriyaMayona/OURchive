# OURchive 作品素材导入说明

## 推荐放置位置

把本文件夹内的 PNG 图片复制到项目目录：

```text
D:\OURchive\my-app\public\works\reimu-birthday\
```

网站中引用路径统一使用：

```text
/works/reimu-birthday/文件名.png
```

## 文本版《神社来信》

灵梦：

今年的神社还是一样安静，却因为你的生日，多了一点热闹。

清晨的风铃、赛钱箱旁的蛋糕、大家悄悄准备的礼物，都在等你回头发现。

愿你新的一年也能被温柔对待，也愿那些被你守护的日常，继续闪闪发亮。

生日快乐。

——未央
